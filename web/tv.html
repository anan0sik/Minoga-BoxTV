1. Статус приложения

Приложение «Minoga TV Box» (далее — «Программа») представляет собой программный проигрыватель (медиаплеер), предназначенный для воспроизведения потокового аудио- и видеоконтента по протоколам, поддерживаемым сетью Интернет. Программа работает по принципу интернет-браузера и лишь визуализирует данные по ссылкам, указанным пользователем.

• Разработчик не контролирует, не модерирует и не несет ответственности за содержание, качество, легальность и доступность медиапотоков, которые пользователь открывает с помощью Программы.

3. Обязательства и ответственность пользователя

• Пользователь самостоятельно находит, формирует и загружает в Программу плейлисты и ссылки на медиапотоки.
